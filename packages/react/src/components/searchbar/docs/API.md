| Nom             | Type                                 | Valeur par défaut | Description                                                                                                                           |
| --------------- | ------------------------------------ | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| appearance      | primary \| secondary                 | "primary"         | Apparence de la Searchbar. `primary` affiche un bouton de recherche séparé. `secondary` affiche une icône de recherche dans le champ. |
| assistiveText   | string                               | -                 | Texte d’assistance associé au champ.                                                                                                  |
| compactSpacing  | boolean                              | -                 | Réduit la hauteur et les espacements internes.                                                                                        |
| disabled        | boolean                              | false             | Désactive la saisie et les actions de recherche.                                                                                      |
| id              | string                               | -                 | Identifiant HTML du champ de saisie.                                                                                                  |
| label           | string                               | "Rechercher"      | Libellé utilisé comme placeholder et comme nom accessible du bouton de recherche.                                                     |
| onChange        | (input: string \| undefined) => void | -                 | Callback appelé lorsque la valeur saisie change.                                                                                      |
| onClear         | () => void                           | -                 | Callback appelé lors de l’effacement de la valeur.                                                                                    |
| onSearch        | (input: string \| undefined) => void | -                 | Callback appelé par le bouton de recherche ou à l’appui sur Entrée.                                                                   |
| showResetButton | boolean                              | true              | Affiche le bouton d’effacement lorsque le champ contient une valeur.                                                                  |
| value           | string                               | -                 | Valeur contrôlée du champ.                                                                                                            |
| width           | number                               | -                 | Largeur transmise au champ de saisie.                                                                                                 |
