`RadioButton` permet de sélectionner une option parmi plusieurs choix partageant le même groupe.
Il prend en charge les états désactivé, en erreur, en lecture seule et sélectionné.

```tsx
import RadioButton from "@design-system-rte/react";

const App = () => {
  return <RadioButton label="Radio Button" value="radio-button" groupName="radio-group" />;
};
```
