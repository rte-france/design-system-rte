### Q : Mon tag ne s’affiche pas

R : Le Tag ne s’affiche pas lorsque `iconName` n’est pas valide. Avant le rendu, le composant vérifie que la valeur correspond à une clé `RegularIconIdKey` ou `TogglableIconIdKey` valide.

Lorsqu’un nom d’icône non valide est fourni, un avertissement doit s’afficher dans la console. Utilisez une clé d’icône valide pour vous assurer que le Tag est rendu.
