`RadioButtonComponent` permet de sélectionner une option parmi plusieurs choix partageant le même groupe.
Il prend en charge les états désactivé, en erreur, en lecture seule et sélectionné.

```ts
import { RadioButtonComponent } from "@design-system-rte/angular";
```

```html
<rte-radio-button label="Radio Button" value="radio-value" groupName="radio-group"></rte-radio-button>
```
