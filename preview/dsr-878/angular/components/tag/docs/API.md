### Inputs du composant `rte-tag`

| Input          | Type                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Valeur par défaut | Description                                                                                                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| tagType        | status \| decorative                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | status            | Définit si le Tag représente un statut (`status`) ou une information décorative (`decorative`).                                                                                          |
| status         | success \| information \| warning \| alert                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | success           | Définit le statut affiché. Pour un Tag de type `status`, ce statut détermine automatiquement l'icône affichée.                                                                           |
| color          | brand \| neutral \| neutral-bold \| bleu-iceberg \| bleu-iceberg-bold \| vert-foret \| vert-foret-bold \| violet \| violet-bold \| bleu-rte \| bleu-rte-bold \| bleu-digital \| bleu-digital-bold \| marine \| marine-bold \| bleu-petrole \| bleu-petrole-bold \| bleu-cyan \| bleu-cyan-bold \| vert \| vert-bold \| vert-indications \| vert-indications-bold \| vert-digital \| vert-digital-bold \| jaune \| jaune-bold \| jaune-ocre \| jaune-ocre-bold \| jaune-indications \| jaune-indications-bold \| saumon \| saumon-bold \| rose \| rose-bold \| fuschia \| fuschia-bold \| rouge-indication \| rouge-indication-bold \| taupe \| taupe-bold | brand             | Définit la couleur décorative utilisée lorsque `tagType` vaut `decorative`.                                                                                                              |
| compactSpacing | boolean                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | false             |                                                                                                                                                                                          |
| label          | string                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | ""                |                                                                                                                                                                                          |
| iconName       | RegularIconIdKey \| TogglableIconIdKey \| undefined                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | -                 | Définit l'icône affichée dans le Tag décoratif. Pour un Tag de type `status`, l'icône correspondant au `status` est prioritaire. Un nom d'icône invalide empêche l'affichage de l'icône. |
| ariaLabel      | string \| undefined                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | -                 | Définit le nom accessible transmis à l'attribut `aria-label` du conteneur du Tag.                                                                                                        |
