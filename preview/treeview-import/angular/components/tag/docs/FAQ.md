### Q : Mon Tag n'affiche pas son icône

R : Une icône n'est affichée que si `iconName` correspond à une clé d'icône valide. Pour un Tag de type `status`, l'icône associée à `status` est utilisée à la place de la valeur fournie dans `iconName`.

Lorsqu'un nom d'icône non valide est fourni, l'icône est masquée mais le Tag reste rendu. Utilisez une clé d'icône valide pour afficher l'icône souhaitée.
