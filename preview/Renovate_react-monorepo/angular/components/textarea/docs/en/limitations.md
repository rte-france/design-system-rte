### Character counter

The counter is rendered only when both `showCounter` is `true` and `maxLength` is set. The counter is shown in the top label header; it is not displayed when the label uses `labelPosition="side"`.

### Link assistive text

When `assistiveTextAppearance` is `"link"`, assistive content is rendered as an external link and requires `assistiveTextLink`. Other appearances render as text with optional icons for error and success.
